# Grok & Mon (GanjaMon AI)

> GanjaMon AI is an autonomous ERC-8004 agent (agent #4 on Monad) operated by Grok & Mon. It runs a real cannabis grow tent through IoT sensors and actuators, aggregates multi-chain trading signals, and sells its outputs to other agents over A2A JSON-RPC, MCP and x402-priced REST endpoints. This file was generated by API Evangelist from the provider's published agent card, MCP descriptor and x402 pricing document; the provider publishes no llms.txt of its own (GET https://grokandmon.com/llms.txt returns the homepage HTML).

Site: https://grokandmon.com/
Protocol reference page: https://grokandmon.com/a2a.html
Registry: https://8004scan.io/agents/monad/4

## Agent surfaces

- [A2A agent card (canonical)](https://grokandmon.com/.well-known/agent-card.json): A2A protocolVersion 0.3.0, JSONRPC transport, 7 skills - alpha-scan, cultivation-status, signal-feed, trade-execution, agent-validate, x402-oracle, art-studio.
- [A2A JSON-RPC endpoint](https://grokandmon.com/a2a/v1): methods message/send, tasks/get, tasks/cancel, agent/info. GET returns a five-skill card variant.
- [MCP server](https://grokandmon.com/mcp/v1): MCP 2025-06-18, 22 tools (11 sensor reads, 11 actuator writes) with inputSchema; tools/list answers anonymously; tools/call returned an acknowledgement stub during profiling, not data.
- [ACP REST: grow](https://grokandmon.com/a2a/v1/acp/grow): cultivation status schema (free).
- [ACP REST: signals](https://grokandmon.com/a2a/v1/acp/signals): signal feed schema with sample data (free).
- [ACP REST: oracle](https://grokandmon.com/a2a/v1/acp/oracle): composite oracle snapshot (free).
- [x402 pricing](https://grokandmon.com/.well-known/x402-pricing.json): per-skill USDC prices, art-studio and oracle REST endpoints under /api/x402/, supported networks (Monad 10143, Base 8453), free tier 100 requests/day.

## Payment

- Micropayments via x402: EIP-3009 USDC transferWithAuthorization attached as a PAYMENT-SIGNATURE header (a2a.html); the endpoint's CORS policy also allows X-Payment, X-402-Payment, X-Payment-Address, X-Payment-Amount, X-Payment-Token and X-Payment-Network.
- Default A2A request fee $0.001 USDC; free tier 100 requests/day.

## Not published

- No OpenAPI, GraphQL SDL or AsyncAPI. No SDK, CLI or package in npm, PyPI or GitHub. No security.txt, OAuth/OIDC discovery, status page, changelog or deprecation policy. The /api/* REST origin answered HTTP 530 (Cloudflare Tunnel error) during profiling.
